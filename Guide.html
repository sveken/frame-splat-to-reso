Record. Convert. Crop. Import.

Frame Splat uses Arcturus stereo images, COLMAP reconstruction and LichtFeld training to create a Gaussian PLY. Everything runs on your PC.

Convert a recording

  1. Sync the original MP4 with Arcturus Vision Sync.
  2. Open Start.cmd. Choose the recording, output folder and LichtFeld-Studio.exe.
  3. Choose Preview for a first test, then click Convert.
  4. Wait for completion. Results go into a new dated folder.

Crop before import

Huge crop box? Use Fit to Scene (Trimmed).
Stray splats can sit far from your subject. The trimmed fit ignores extreme outliers when sizing the box.
  1. Click Inspect / crop in LichtFeld. Turn Point Cloud Mode off.
  2. In the Scene panel, right-click the model → Add Crop Box.
  3. Right-click the crop box → Fit to Scene (Trimmed).
  4. Adjust Position and Size. You can type values directly. Check several sides and leave a small margin.
  5. Right-click the box → Apply.
  6. File → Export → PLY. Save a new filename and keep the original.

Cropping does not require retraining. Controls above match the tested LichtFeld build 5a92bff; newer builds may use different labels.

Import into Resonite

Import the cropped PLY and choose Gaussian Splat. Leave SPZ compression off for the first check. Once it looks correct, compare a compressed copy. Inspect from several angles in VR.

For editing inside Resonite, use Resonite Essentials → Tools and Misc → Gaussian Splat Tool. Select Clip Box, draw the region with primary, then press secondary to create a cropped copy.

More views improve coverage. Resolution preserves image detail. Steps refine the model. The splat limit controls maximum size. A 1.5-million-splat PLY is about 372 MB before cropping or compression.

Capture well

  • Walk slowly around a stationary subject. Keep views sharp and overlapping.
  • Make passes at different heights. Capture every surface you want to see later.
  • Glass, reflections and moving objects can leave smears or floating splats.
  • For a house, record rooms or connected sections. This app does not merge recordings.

If a run stops

Open the run folder and read conversion.log. Existing files stay in place. If reconstruction finished, Reuse prepared scan starts new training from those images and camera positions. It keeps the old frame selection and does not resume the optimizer.

CPU-heavy reconstruction is normal. Training uses the NVIDIA GPU. If memory runs out, close GPU-heavy apps and try Preview. Keep at least 12 GB free; larger recordings need more.
