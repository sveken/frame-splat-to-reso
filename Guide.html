Record. Convert. Crop. Import.

Choose Splat, Mesh or Both. Frame Splat uses Arcturus stereo images and COLMAP reconstruction. LichtFeld trains Gaussian splats; COLMAP and OpenMVS create textured meshes. Everything runs on your PC.

Convert a recording

  1. Sync the original MP4 with Arcturus Vision Sync.
  2. Open Start.cmd. Choose the recording, output folder and output type. Choose LichtFeld-Studio.exe for Splat / Both; Mesh does not need it.
  3. Choose Preview for a first test, then click Convert. Existing installs should rerun Setup.cmd once to add the mesh tools.
  4. Wait for completion. Results go into a new dated folder.

Import a textured mesh

Click Open mesh files. Import mesh/scene.obj into Resonite as a regular 3D model. Keep its MTL and texture images together in the same folder. Try an Unlit / PBR Emissive material to preserve the photographed lighting.

Check several views, scale and orientation. Missing surfaces still need cleanup. A visual mesh is not automatically a clean collision mesh. Both output types share the original reconstruction, but separate recordings still need alignment.

Crop a splat before import

Huge crop box? Use Fit to Scene (Trimmed).
Stray splats can sit far from your subject. The trimmed fit ignores extreme outliers when sizing the box.
  1. Click Inspect / crop in LichtFeld. Turn Point Cloud Mode off.
  2. In the Scene panel, right-click the model → Add Crop Box.
  3. Right-click the crop box → Fit to Scene (Trimmed).
  4. Adjust Position and Size. You can type values directly. Check several sides and leave a small margin.
  5. Right-click the box → Apply.
  6. File → Export → PLY. Save a new filename and keep the original.

Cropping does not require retraining. Controls above match the tested LichtFeld build 5a92bff; newer builds may use different labels.

Import into Resonite

Import the cropped PLY and choose Gaussian Splat. Leave SPZ compression off for the first check. Once it looks correct, compare a compressed copy. Inspect from several angles in VR.

For editing inside Resonite, use Resonite Essentials → Tools and Misc → Gaussian Splat Tool. Select Clip Box, draw the region with primary, then press secondary to create a cropped copy.

More views improve coverage. Resolution preserves image detail. Steps refine the model. The splat limit controls maximum size. A 1.5-million-splat PLY is about 372 MB before cropping or compression.

For meshes, Preview uses up to 768 px images, a 100,000-triangle target and 2,048 px textures. Detailed uses 1,600 px images, a 300,000-triangle target and 4,096 px textures. Room uses the same image/texture limits with a 600,000-triangle target. Texture limits apply to each image; multiple textures may be generated. Targets are approximate.

Mesh processing: Faster (up to 800 px) caps surface resolution at 800 px and lowers it further if needed to fit RAM and avoid repeatedly reloading files. This may reduce small surface details. Full detail preserves the preset's surface resolution, using a memory-sized cache if needed; large rooms can still take hours. Both retain original depth maps and photo texture quality. The actual choice is recorded in fusion-plan.json.

Balanced (up to 1,024 px) is the middle option: it uses more available RAM for surface detail than Faster, reserves at least 2 GiB for other activity, and lowers resolution if necessary to avoid disk caching. It controls quality, not a target processing time. Photo texture quality stays the same.

On new scans, Faster also calculates depth at up to 800 px and Balanced at up to 1,024 px; Full detail keeps the preset limit. Preview never exceeds 768 px. Recovering saved depths can be much quicker than generating a fresh room from scratch.

Capture well

  • Walk slowly around a stationary subject. Keep views sharp and overlapping.
  • Make passes at different heights. Capture every surface you want to see later.
  • Glass, reflections and moving objects can leave smears or floating splats.
  • For a house, record rooms or connected sections. This app does not merge recordings.

If a run stops

Open the run folder and read conversion.log. Existing files stay in place. If camera reconstruction finished, Reuse prepared scan starts fresh splat training or mesh generation from those images and camera positions. It keeps the old frame selection and does not resume partial depth calculation or the optimizer. In Both mode, a completed splat remains available if mesh generation fails.

If depth generation finished, an advanced recovery command can reuse those maps: .venv\Scripts\python.exe flow.py --job "D:\path\to\existing-run" --resume-mesh. Wait for the old worker to stop first. Recovery restarts combining, meshing and texturing while preserving the finished splat.

If a completed surface is available from a failed texture attempt, recovery retries only texturing. A Windows texture access violation gets one retry with seam blending disabled; successful exports note that photo patch boundaries may be visible in mesh/IMPORT.txt.

CPU-heavy reconstruction is normal. Splat training and mesh depth estimation use the NVIDIA GPU. Mesh construction and texturing use the CPU. If memory runs out, close GPU-heavy apps and try Preview. Keep at least 12 GB free for Splat or 25 GB for Mesh / Both; larger recordings need more.
